# 2026-07-17 — Ondata 1a: login

## Obiettivo
Prima pagina dell'ondata auth: login riallineata al demo (colonna centrata, card con filo gradiente, claim in Bricolage), sfruttando la quasi-staticità della pagina per il massimo impatto visivo.

## File toccati
- `src/main/webapp/WEB-INF/template/login.html` — riscritto il layer di presentazione: via i wrapper `display:table` e tutti gli stili inline; nuova struttura `.auth-wrap` / `.auth-card`. La pagina ora carica font + `wera-theme.css` (prima non caricava il tema: aveva un head proprio).
- `src/main/webapp/css/wera-theme.css` — sezione 19: stili `.auth-*` riusabili per registrazione/resetpassword/newpassword (prossime consegne dell'ondata 1).

## Componenti: prima -> dopo
- wrapper `display:table` con inline style -> `.auth-page` flex centrato, sfondo `--bg` con due glow radiali caldi (ambra/ember) appena percettibili
- panel Bootstrap raggio 5px -> `.auth-card`: bianca, raggio 18px, ombra profonda, filo gradiente 4px sul bordo superiore
- tagline `h4` inline -> `.auth-claim` in Bricolage Grotesque 19px
- errore `<p><center>` -> `.auth-error` (chip rosso soft, nascosto se vuoto via `:empty`)
- link "Password dimenticata?"/"Registrati" -> stile coerente, hover accento
- bottone Login -> `.btn-primary` gradiente del tema (block)
- footer -> `.auth-foot` muted

## Cosa NON e stato toccato (conferma)
Form identico: `action="astro"`, `method="post"`, `id="Login"`, hidden `FUNCTIONID=Home`, blocco `SESSION_TOKEN` e `ERROR_MESSAGE` FreeMarker preservati carattere per carattere, `name`/`id`/`required` di USERNAME e PASSWORD invariati, script jquery.validate e ordine dei `<script>` in fondo invariati, href `ResetPassword`/`Registrazione` invariati.
Nota: il blocco checkbox vuoto (nessun name/id/handler, solo markup morto) è stato rimosso.
